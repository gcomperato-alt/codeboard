CodeBoard

Air traffic control for AI agents. Route tasks, check handoffs, prevent context crashes.

1. Human Input Messy request enters the tower.
2. Prompt Clearance CoThink-style refinement checks intent.
3. Agent Routing Research, writer, code or planner agent receives task.
4. Safe Handoff Output is checked before the next agent takes over.
Example:
User: “Plan my JB trip ah.”
CodeBoard keeps the halal requirement, border timing, budget and transport context alive across agents. No more agent forgetting the important bit halfway.
Built from canornot + CoThink logic: Human → Prompt → Agent → Agent → Output.
